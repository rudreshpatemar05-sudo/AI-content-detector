# Training and Testing Guide

This document explains the training and testing workflow for the AI content detector project.

## 1. Project goal

The project builds a text classifier that predicts whether a given passage is likely written by a human or generated by AI. It uses:

- TF-IDF word and character features
- Stylometric features such as word length, punctuation rate, sentence length, and type-token ratio
- Logistic Regression classifiers
- Calibration and thresholding for probability-based decisions

The main scripts are in the `src/` folder and are executed in a specific order.

---

## 2. Data preparation workflow

### File: `src/prepare_data.py`

This is the main data preparation script.

Purpose:
- Downloads or loads the HC3 dataset
- Loads GPT-wiki paired data
- Cleans the text and filters poor-quality rows
- Combines multiple datasets into a consistent format
- Splits data into train/validation/test groups
- Balances training data for the human/AI classes

Key functions:
- `clean_text(value)`
  - Normalizes whitespace and removes extra spaces
- `is_english_text(text)`
  - Keeps only text that looks like valid English content
- `clean_frame(frame)`
  - Removes invalid rows and standardizes columns
- `download_hc3_jsonl()`
  - Downloads HC3 data if missing
- `load_hc3()`
  - Converts the HC3 JSONL into a labeled DataFrame
- `load_gpt_wiki()`
  - Loads paired human and AI text from the GPT-wiki dataset
- `split_by_group(frame)`
  - Keeps related text groups together in the same split to reduce leakage
- `balance_train(frame)`
  - Balances the training set by class count

Output files:
- `data/processed/train.csv`
- `data/processed/val.csv`
- `data/processed/test.csv`
- `data/processed/heldout_wikicsai.csv`

Typical command:

```bash
python src/prepare_data.py
```

## 3. Baseline and model training scripts

### File: `src/train.py`

This file acts as a compatibility entry point. It simply imports and runs the main TF-IDF training script.

```python
from src.train_tfidf import main
```

Purpose:
- Provides a simple alias for the main model training flow

Typical command:

```bash
python src/train.py
```

### File: `src/train_tfidf.py`

This is the main TF-IDF logistic regression training script.

Purpose:
- Builds TF-IDF features from the training set
- Trains a Logistic Regression classifier
- Tunes the regularization parameter `C`
- Fits a calibration model on validation predictions
- Saves the trained model and calibrator

Typical training steps:
1. Load train and validation CSV files
2. Build TF-IDF vectorizer for word and character n-grams
3. Train candidate models across multiple `C` values
4. Select the best model using validation F1
5. Fit a calibration logistic model to convert raw probabilities into calibrated probabilities
6. Save artifacts to `models/`

Output files:
- `models/tfidf_lr.joblib`
- `models/tfidf_calibrator.joblib`

---

### File: `src/train_robust.py`

This is the advanced training script used for the final robust detector.

Purpose:
- Combines TF-IDF features with stylometric features
- Trains a more robust model using lexical + writing-style signals
- Performs validation-based calibration
- Selects thresholds for human and AI decisions
- Saves reliability plots and top feature summaries

Important parts:
- `humanize(text)`
  - Rewrites AI-like phrasing into simpler human-like wording for augmentation
- `augment_ai_training(train)`
  - Adds light augmentation for AI-labeled rows
- `build_features()`
  - creates a `FeatureUnion` with:
    - word TF-IDF
    - character TF-IDF
    - styled feature pipeline
- `fit_variant(...)`
  - trains and compares multiple `C` values
  - saves the best model and calibrator
- `select_thresholds(y, p)`
  - chooses human and AI decision thresholds based on validation precision
- `save_reliability(y, p, name)`
  - produces calibration reliability charts

This script is the main model training pipeline for the app and evaluation system.

Typical command:

```bash
python src/train_robust.py
```

Output files include:
- `models/tfidf_lr_robust_noaug.joblib`
- `models/tfidf_lr_robust_aug.joblib`
- `models/tfidf_lr_robust_noaug_calibrator.joblib`
- `models/tfidf_lr_robust_aug_calibrator.joblib`
- `results/robust_training.json`
- `results/top_features_robust_noaug.json`
- `results/top_features_robust_aug.json`

---

### File: `src/prepare_raid_sample.py`

This script prepares a RAID-based sample for adversarial and source-held-out evaluation.

Purpose:
- Pulls RAID data shards from Hugging Face
- Matches human text with AI text from the same source
- Creates a paired dataset for robust evaluation
- Ensures train/validation/test splits do not overlap in source group IDs
- Saves a RAID sample and manifest

Key outputs:
- `data/raw/raid_sample.csv`
- `results/raid_sample_manifest.json`

Typical command:

```bash
python src/prepare_raid_sample.py
```

## 4. Testing and evaluation workflow

### File: `src/evaluate.py`

This is the main model evaluation script.

Purpose:
- Loads trained model + calibrator
- Scores validation, test, held-out, RAID, and evasion splits
- Computes metrics like:
  - Accuracy
  - Precision
  - Recall
  - F1 score
  - ROC-AUC
  - Brier score
  - confusion matrix
- Saves metrics and comparison plots to `results/`

Important functions:
- `score_model(model_path, calibrator_path, frame)`
  - returns calibrated probabilities
- `metric_row(model_name, split_name, frame, probabilities)`
  - calculates the metrics for one split

Evaluation logic:
- loads validation and test data
- scores multiple model variants
- chooses the selected model by validation performance
- copies the winning model into `models/tfidf_lr.joblib`
- writes the final evaluation report

Typical command:

```bash
python src/evaluate.py
```

Output files include:
- `results/robust_evaluation.json`
- `results/evaluation_metrics.json`
- `results/comparison.csv`
- `results/error_analysis.csv`
- confusion matrix CSV files in `results/`

## 5. Testing scripts for edge cases and custom input

### File: `src/create_evasion_test.py`

This script prepares the evasion evaluation set.

Purpose:
- Creates a small challenge dataset for testing whether paraphrased or manipulated AI text is missed
- Helps validate robustness against adversarial examples

Typical command:

```bash
python src/create_evasion_test.py
```

### File: `src/predict.py`

This file contains the prediction logic used by the app and analysis utilities.

Purpose:
- Loads the trained model and calibrator
- Predicts overall AI probability for a passage
- Scores sentence-level segments for local explanations
- Splits passages into paragraph-like chunks and sentence windows

Typical use:
- called from `app/streamlit_app.py`
- used for interactive analysis in the browser

## 6. Execution order for the full workflow

Run the project in this order:

```bash
python src/prepare_data.py
python src/create_evasion_test.py
python src/train_robust.py
python src/evaluate.py
streamlit run app/streamlit_app.py
```

This sequence covers:
1. Data preparation
2. Evasion set creation
3. Model training
4. Evaluation
5. Web app demo

## 9. Summary

The project trains and tests a detector in a structured pipeline:

- data is cleaned and split,
- the classifier is trained on labeled human/AI text,
- the model is calibrated with validation predictions,
- thresholds are selected for decision-making,
- and the final model is evaluated on test, held-out, RAID, and evasion sets.

This makes it suitable for both research and practical demonstration in a Streamlit application.
